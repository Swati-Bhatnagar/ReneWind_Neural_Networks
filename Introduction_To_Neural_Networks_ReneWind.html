Data Overview

The dataset contains 20,000 observations with 40 numerical predictor variables and a binary target variable indicating failure (1) or no failure (0). Missing values are minimal and present only in a few columns. The dataset is highly imbalanced, with a very small proportion of failure cases, making recall an important metric.
